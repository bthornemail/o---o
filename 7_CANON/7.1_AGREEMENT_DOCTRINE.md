# Agreement Doctrine

Agreement in OMI is not passive approval, social consensus, or majority vote. Agreement is the moment an object becomes structurally valid, addressable, replayable, and projectable across carrier surfaces.

## Canonical Pipeline

```text
A frame is valid iff Q_frame(S) = 0.
A valid frame yields one truth row: (LL, NN, MM).
A truth row is accepted iff MM resolves from NN under the LL-modulated Delta Law within the bounded Fano window.
An accepted row writes a receipt into the 5040-slot replay ring.
Only after validation, resolution, and receipt may the object be projected into DOM, SVG, JSON Canvas, IPv6, QR, portal UI, or reader lenses.
Projection is never authority.
```

## What Agreement Is

Agreement is a structural path from uncertainty to inspectable relation:

```text
declared activity
  -> bounded frame
  -> Q_frame validation
  -> truth-row extraction
  -> Delta/Fano resolution
  -> receipt write
  -> projection
  -> inspection
```

This does not require everyone to share the same belief, interpretation, or opinion. It requires a shared frame whose admission, resolution, and receipt can be inspected.

## What Agreement Is Not

Agreement is not:

```text
rendered appearance
platform acceptance
majority vote
glyph meaning
color meaning
portal trust
reader lens state
```

Those can help people inspect an object, but they do not authorize the object.

## Disagreement

Disagreement is treated as a missing or unresolved structure, not as a reason to erase the object.

| Disagreement | Missing Structure | Canonical Response |
|--------------|-------------------|--------------------|
| What is this? | Boundary | Reveal or create object frame |
| Who said this? | Source | Show provenance object |
| What changed? | Replay | Show receipt chain |
| Why trust it? | Validation evidence | Show `Q_frame`, truth row, and receipt |
| Where does it belong? | Containment | Show hierarchy |
| Can it open elsewhere? | Carrier projection | Export safe projection |

Doctrine:

```text
disagreement -> missing structure -> new object/path/test/receipt
```

## Projection Rule

Projection is downstream:

```text
validate -> resolve -> record -> project -> inspect
```

Never:

```text
render -> believe
```

Fonts, glyphs, Unicode codepoints, colors, SVG, DOM, ShadowDOM, JSON Canvas, QR, and portal UI are all recoverable views under rules.
